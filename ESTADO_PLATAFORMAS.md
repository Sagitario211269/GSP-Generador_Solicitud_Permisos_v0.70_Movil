# Separación de plataformas — GSP móvil 0.8.5

Esta distribución es exclusivamente la aplicación web progresiva (PWA) para navegadores móviles y de escritorio.

No requiere Electron, `main.js`, `preload.js`, `electron-builder`, instaladores NSIS ni ejecutables portables. Tampoco incluye `COMPILAR_WINDOWS.bat`.

La versión de escritorio GSP PC conserva su propio proyecto y proceso de compilación, independiente de este repositorio móvil.
