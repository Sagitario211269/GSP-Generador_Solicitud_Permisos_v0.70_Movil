GSP MÓVIL v0.8.5 — PROYECTO PWA DEPURADO

Esta distribución es exclusivamente para GitHub Pages.

PUBLICACIÓN
1. Descomprima el archivo ZIP.
2. Suba TODO el contenido de la carpeta del proyecto a la raíz del repositorio GitHub Pages, reemplazando los archivos anteriores.
3. Confirme los cambios (Commit changes).
4. Espere la publicación y abra la aplicación mediante HTTPS.
5. Cierre completamente la PWA anterior y vuelva a abrirla con internet para actualizar la caché v0.8.5.

DEPURACIÓN
- Se retiraron Electron, electron-builder y las tareas de compilación Windows.
- Se retiraron main.js, preload.js y COMPILAR_WINDOWS.bat.
- Se retiraron auditorías y módulos exclusivos de escritorio.
- package.json queda únicamente para ejecutar auditoría y pruebas con Node.js; no hay dependencias de producción ni de Electron.

La versión PC conserva su proyecto independiente. No mezcle archivos del proyecto PC con este repositorio móvil.
